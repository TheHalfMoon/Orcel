## Segmented control

2 to 4 views of the same data. Track `bg-sunken`, radius 8, 2px padding; segments 28 high, 12.5/500 `fg-muted`; selected segment `bg-surface text-fg-default shadow-sm`.
**Primitive**: Base UI `ToggleGroup` (single, not deselectable). Arrows move between segments. `aria-label` on the group ("View").

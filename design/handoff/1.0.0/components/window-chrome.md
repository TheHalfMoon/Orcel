## Window chrome (Windows 11, shared convention)

40px titlebar drawn by the app (drag region), mark 16 and window title 12/500, optional search (28) and Shadow Mode switch inside it; caption buttons 46 x 40 flush right: minimise, maximise/restore, close. Hover: `bg-hover`; close hover `#C42B1C` with white glyph (system colour, not brand red). Tauri: `decorations: false` + `data-tauri-drag-region`.

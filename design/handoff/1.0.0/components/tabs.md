## Tabs

36 high tabs, 13/500 `fg-muted`, selected `fg-default` with a 2px ink underline inset 10px; optional count pill (11/500 on `bg-sunken`). Bottom hairline `border-default`.
**Primitive**: Base UI `Tabs` (Tabs.List, Tabs.Tab, Tabs.Indicator for the underline, Tabs.Panel). Arrows move, Home/End jump, activation on focus for lightweight panels, manual (Enter) for heavy ones.

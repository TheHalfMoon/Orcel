## Takeover (shared convention)

1. Agent working (Shadow surface optional). Button **Take over** (hand icon, T).
2. Banner **"You're in control. The agent is paused."** (control banner, `you-soft`). The agent's cursor (sky) disappears; the person's cursor and focus are the only ones. Chip: Paused. Primary **Hand back** (H).
3. Hand back popover: optional note textarea ("Fixed the postcode. Continue from the payment step."), ghost "Keep control", primary "Hand back".
4. Agent chip **"Reassessing after your changes"** (running) with a "What changed" summary: each field you changed (old → new), your note, then the agent's next step and whether it will ask you before acting.
Live region announces each transition politely.

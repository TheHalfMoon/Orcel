## Microsoft WebView2 loader (approved for development and internal testing only)

`webview2-com-sys` 0.39.1 declares MIT for its Rust bindings, but its crate also ships Microsoft's prebuilt WebView2 loader, and with the MSVC toolchain the shell statically links `WebView2LoaderStatic.lib`. The loader is Microsoft's, under the Microsoft WebView2 SDK license terms; it is not MIT or Apache-2.0, and `deny.toml` records the crate as `MIT AND LicenseRef-Microsoft-WebView2-SDK`.

**Founder decision (2026-11-16):** approved for development and internal testing only. This does not authorize public distribution of the shell (founder decision 6), and Microsoft's redistribution obligations under the WebView2 SDK license must be verified before any public release.

**License text.** The `webview2-com-sys` 0.39.1 package as shipped on crates.io (and extracted in the local cargo registry) contains no copy of Microsoft's WebView2 SDK license text: its files are the Rust sources, `Cargo.toml`, `Cargo.lock`, `README.md`, `CHANGELOG.md`, `build.rs` and the binaries below. The text is therefore not reproduced here; it ships with Microsoft's WebView2 SDK (the `Microsoft.Web.WebView2` package, version 1.0.3800.47, matching the loader's file version) and must be obtained from Microsoft and added here before any distribution. Nothing below paraphrases it.

# kaf Agent App

This project uses the kaf framework. Before writing code, read the relevant guide
from the installed kaf package docs. In most installs, those docs are at
`node_modules/kaf/docs/`. In workspaces or local package installs, resolve the
installed `kaf` package location first and read its `docs/` directory. If
package docs are unavailable, use https://github.com/TheHalfMoon/kaf/docs as a fallback.

Before implementing an integration yourself, use
`kaf registry search <query>` or `kaf registry list` to discover available
integrations. Inspect one with `kaf registry view <item>`, then install it with
`kaf add <item>`.

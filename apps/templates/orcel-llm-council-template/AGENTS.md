# orcel Agent App

This project uses the orcel framework. Before writing code, read the relevant guide
from the installed orcel package docs. In most installs, those docs are at
`node_modules/@orcel/orcel/docs/`. In workspaces or local package installs, resolve the
installed `orcel` package location first and read its `docs/` directory. If
package docs are unavailable, use https://github.com/TheHalfMoon/orcel/docs as a fallback.

Before implementing an integration yourself, use
`orcel registry search <query>` or `orcel registry list` to discover available
integrations. Inspect one with `orcel registry view <item>`, then install it with
`orcel add <item>`.

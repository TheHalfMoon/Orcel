# Orcel public brand — Orca Eye

The founder-selected current brand is Orca Eye: a single-color circle with an orca eye patch cut out of it, and a lowercase orcel wordmark in outlined Unbounded SemiBold. Black #080808, white #FFFFFF, and Signal Lime #D4FF3F for actions only, never inside the mark.

Source vectors are generated from scripts/sync-brand.mjs and mirrored here for GitHub Pages. Local Sharp and Python build PNG/ICO, asset manifest, social preview and Orcel-Identity-Kit-v3.zip. See assets/brand/IDENTITY.md for guidelines.

Old orbit, OI and Signal media filenames are retained only for public URL compatibility; they contain the updated Orca Eye art. Past history and released versions are not rewritten. No software capability is implied by these changes.

# Orcel public brand — identity v4

The founder-selected current brand is the Night Window, a Halfmoon product: a desktop window holding Halfmoon's half moon, with a lowercase orcel wordmark in outlined Bricolage Grotesque SemiBold. Midnight #090C12, white #FFFFFF, Lunar #F5F4F0, Lavender #A6ACE6 for the moon, Red #B31B1B only for deny and revoke.

Source vectors are generated from scripts/sync-brand.mjs and mirrored here for GitHub Pages. Local Sharp and Python build PNG/ICO, asset manifest, social preview and Orcel-Identity-Kit-v4.zip. See assets/brand/IDENTITY.md for guidelines.

Old orbit, OI, Signal and Orca Eye media filenames are retained only for public URL compatibility; they contain the updated v4 art. Past history and released versions are not rewritten. No software capability is implied by these changes.

# Orcel public brand — identity v5

The founder-approved current brand is "People first": a vermilion human figure and a lowercase orcel wordmark in outlined Inter Display, with the Orcel product icon family. Vermilion #DB2532, Ink #141414, Deep Navy #182437, Cobalt #2354D4, Orange #F5724D, Sky #BFD8F7, Ivory #F7F3EB.

Source vectors are generated from scripts/sync-brand.mjs and mirrored here for GitHub Pages. Local Sharp and Python build PNG/ICO, asset manifest, social preview and Orcel-Identity-Kit-v5.zip. See assets/brand/IDENTITY.md for guidelines.

Old orbit, OI, Signal, Orca Eye and Night Window media filenames are retained only for public URL compatibility; they contain the updated v5 art. Past history and released versions are not rewritten. No software capability is implied by these changes.

# fixture-button (synthetic)

Synthetic component spec used only by the handoff checker tests.

## States

default, hover, focus, active, disabled, loading.

## Keyboard

Tab reaches it; Enter and Space activate it.

## Accessibility

Visible focus ring using color.focus, 2px, 3:1 against the surface.

## Motion

motion.duration.base with motion.easing.standard; motion.duration.reduced under reduced motion.

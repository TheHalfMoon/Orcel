# Orcel — Brand Kit v5, "People first"

The founder-approved Orcel identity: a vermilion human figure beside a lowercase black orcel wordmark in outlined Inter Display, the principle "One person. Many agents.", a five-icon product family, and the palette Vermilion #DB2532, Ink #141414, Deep Navy #182437, Cobalt #2354D4, Orange #F5724D, Sky #BFD8F7 and Ivory #F7F3EB.

Brand gallery: https://thehalfmoon.github.io/Orcel/brand.html
Versioned ZIP: https://thehalfmoon.github.io/Orcel/brand/Orcel-Identity-Kit-v5.zip
Manifest: https://thehalfmoon.github.io/Orcel/brand/orcel-asset-manifest.json

Canonical construction and professional usage rules: assets/brand/IDENTITY.md.
Canonical generator: scripts/sync-brand.mjs. PNG/ICO/social and ZIP exports: scripts/render-brand.mjs and scripts/export-brand.py. All assets use editable source vectors and local dependencies only, no font binary in the kit and no paid renderers.

The Night Window (v4), Orca Eye, Signal and earlier proposals remain in Git history, not in the current active identity. Old file URLs are compatibility aliases. No historic release binaries or software permissions are changed.

The GitHub README uses `assets/brand/orcel-readme-lockup.svg`, an ivory-backed, generator-produced logo that stays legible in both GitHub light and dark themes.

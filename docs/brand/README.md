# Orcel — Brand Kit v4, a Halfmoon product

The founder-selected Orcel identity is the Night Window: a desktop window holding Halfmoon's half moon, set in Halfmoon's palette (Midnight #090C12, white, Lunar #F5F4F0, Lavender #A6ACE6, Red #B31B1B only to stop) with a lowercase orcel wordmark in outlined Bricolage Grotesque SemiBold. The Halfmoon crescent appears only in the endorsement line "a Halfmoon product".

Brand gallery: https://thehalfmoon.github.io/Orcel/brand.html
Versioned ZIP: https://thehalfmoon.github.io/Orcel/brand/Orcel-Identity-Kit-v4.zip
Manifest: https://thehalfmoon.github.io/Orcel/brand/orcel-asset-manifest.json

Canonical construction and professional usage rules: assets/brand/IDENTITY.md.
Canonical generator: scripts/sync-brand.mjs. PNG/ICO/social and ZIP exports: scripts/render-brand.mjs and scripts/export-brand.py. All assets use editable source vectors and local dependencies only, no font binary in the kit and no paid renderers.

The Orca Eye (November 2026), Signal (October 2026) and earlier OI, orbital and nested proposals remain in Git history, not in the current active identity. Old file URLs are compatibility aliases. No historic release binaries or software permissions are changed.

The GitHub README uses `assets/brand/orcel-readme-lockup.svg`, a midnight-backed, generator-produced white Night Window logo that stays legible in both GitHub light and dark themes.

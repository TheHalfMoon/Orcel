# Orcel — Orca Eye Brand Kit v3

The founder-selected Orcel identity is the Orca Eye: a single-color circle with an orca eye patch cut out of it, paired with a lowercase orcel wordmark in outlined Unbounded SemiBold, presented on #080808. Signal Lime #D4FF3F is reserved for actions and the accent tile; it never appears inside the mark.

Brand gallery: https://thehalfmoon.github.io/Orcel/brand.html
Versioned ZIP: https://thehalfmoon.github.io/Orcel/brand/Orcel-Identity-Kit-v3.zip
Manifest: https://thehalfmoon.github.io/Orcel/brand/orcel-asset-manifest.json

Canonical construction and professional usage rules: assets/brand/IDENTITY.md.
Canonical generator: scripts/sync-brand.mjs. PNG/ICO/social and ZIP exports: scripts/render-brand.mjs and scripts/export-brand.py. All assets use editable source vectors and local dependencies only, no font binary distribution and no paid renderers.

The October 2026 Signal identity and earlier OI, orbital and nested proposals remain in Git history, not in the current active identity. Old file URLs are compatibility aliases. No historic release binaries or software permissions are changed.

The GitHub README uses `assets/brand/orcel-readme-lockup.svg`, a black-backed, generator-produced white Orca Eye logo that stays legible in both GitHub light and dark themes.

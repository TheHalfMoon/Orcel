# Orcel Tool Contract

Status: CANONICAL CONTRACT FOR ORCEL-P16 (SG-000065). Generated by `scripts/generate-tool-contract-doc.mjs` from
`apps/orcel-mcp/src/tool_contract.ts`; `apps/orcel-mcp/src/tool-contract.test.ts` pins the contract against the tool
sources, MCP discovery on every transport, the OAuth scope matrix, the orceld remote-session scope table, the parity
inventory, and this document.

Discovery filtering is never authorization: orceld, the remote-session lease, and the OAuth ceilings enforce every call.

transports serve `desktop_structured` regardless of the configured provider kind, which is metadata and never proof of
identity. A remote connection from any other provider kind is refused.

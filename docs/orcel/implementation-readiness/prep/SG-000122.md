## Why this needs governance

SG-000108's acceptance binds the live browser surface:

- **A13:** "Any live tool is a subset of the twelve SG-000079
  `browser_structured` shapes; the exposure profile, discovery,
  documentation and OAuth scope tables change together." Every BR action
  above is outside the twelve, so exposing any of them widens A13.
- **A7:** exposure, discovery, documentation and OAuth scope tables must
  agree mechanically for any tool added, and remote mapping stays
  disabled.
- **A4:** frames, popups and workers obey the SG-000075 rules; popups are
  mediated as same-origin only (`navigation::mediate_popup`). BR-05 tabs
  (admitting a popup as a new tab of the lifetime) reverses that part of
  the acceptance.
- **BR-04 step 1** (an interactivity flag in observations) changes the
  observation contract that clients rely on.

## Proposed scope (for the activation spec to decide)

| Slice | Authority delta | Approval class (proposed) |
|---|---|---|
| E1. Form actions (fill, select, check), press, hover, text waits | New approval-gated input on admitted pages | SOFT per action, bound to the page generation, element role and name, and value digest; waits are observation (none) |
| E2. Uploads of one host-staged file | New approval-gated **egress** | SOFT bound to origin and file digest; STRONG when policy marks the workspace sensitive (the backlog card's rule) |
| E3. Dialog accept (confirm, prompt) | New approval-gated response | SOFT bound to the dialog text digest; default is dismiss, unchanged |
| E4. Cross-frame observation | None beyond observation | None; cross-origin frames only when admitted in the lifetime |
| E5. The postcondition verifier as a tool | None (read-only) | None |
| E6. BR-05 tabs (list, select, close; popup admission) | Reverses A4's popup rule for admitted origins | Popup to a non-admitted origin stays closed; host-issued tab ids |
| E7. BR-04 step 1 interactivity flag | Observation contract change | None; a versioned observation field |

Each slice is its own PR, and A7 applies to each tool added: exposure
profile, discovery, documentation and OAuth scope tables change together,
and remote mapping stays disabled.

## Security review (preparation)

| Risk | Treatment |
|---|---|
| Upload as data exfiltration | Only one host-staged file per approval, bound to origin and SHA-256; the worker never sees a workspace path; STRONG for sensitive workspaces |
| Form fill of secrets into a hostile page | SOFT approval shows origin, element role and name and a value digest; secret-classified values refused (as XP-19 does for secrets) |
| Approval replay across pages or elements | The digest binds page generation, element identity (role and name, BR-01) and value; stale references are refused, never retargeted silently |
| Dialog spoofing (a page drawing a fake dialog) | Only engine-reported JavaScript dialogs are answerable; their text digest is in the approval |
| Popup and tab admission widening navigation | Popups to non-admitted origins stay closed; admitted ones inherit the lifetime's pins and SG-000075 rules; host-issued tab ids |
| Cross-origin frame content leaking | Frames observed only when their origin is admitted; the same redaction as the main document |
| Clickjacking or covered targets | BR-04 refusal of covered targets stays in force for every pointer action |
| Contract drift between tables | A7's mechanical agreement test runs for each added tool |
| Remote reach | Remote mapping stays disabled; local-only, as SG-000108 |

## Tests to write (per slice)

- Each tool appears in the exposure profile, discovery, documentation and
  OAuth scope tables together, or in none (A7).
- An approval is refused when replayed on another page generation,
  element or value.
- An upload of anything but the staged file is refused; the worker never
  receives a workspace path.
- Dialog accept without approval is refused, and default dismiss is
  unchanged.
- A popup to a non-admitted origin is closed; an admitted popup tab keeps
  the pins (E6).
- The native suite (SG-000108 fixtures) passes with each slice, Windows.

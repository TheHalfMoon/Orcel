Hybrid Computer Use (microsoft/Hybrid-Computer-Use) - adapted source notice

Orcel adapts MIT-licensed source from microsoft/Hybrid-Computer-Use at commit
00eaeebe8ac0d275e46f875bdb5347e5f326faa1 into the private Windows computer
host: the semantic desktop layer (compact accessibility tree with short refs,
ref continuity and staleness, semantic diff, window layout frame, batch plan
compiler) from computer-use/internal/core/ and the layout frame rule from
computer-use/native/windows/ComputerUse.Windows.Runtime/. The adapted files
live under apps/orcel-computer-host/third_party/hcu/semantic/; each names its
donor blob. Orcel's changes are listed in
apps/orcel-computer-host/third_party/hcu/PATCHES.md, and
docs/orcel/hcu_semantic_provenance.json records the provenance. None of the
donor's separately licensed components (Apache-2.0 OSWorld files, the
Playwright-derived Linux indexer, the macOS provider portions, Go
dependencies, NuGet packages) is included.
